## 🆘 TROUBLESHOOTING

| Issue | Solution |
|-------|----------|
| **Images not loading** | Check internet connection; Unsplash might be rate-limited |
| **Cart not saving** | Clear browser cache; enable localStorage |
| **WhatsApp link not opening** | Use latest WhatsApp app; check phone number |
| **Page not rendering** | Try different browser; clear cache & reload |
| **Mobile display issue** | Zoom to 100%; rotate device |
